# HostMonitor

A host-monitoring service, kept as simple as possible. **Planned — there is no code here yet.**

For browser-based checks you can use today:
- [Ping](https://ping.carino.systems/) — latency, jitter and packet loss to any HTTP target, and saved `ping` logs charted
- [Test](https://test.carino.systems/) — network diagnostics: NAT, WebRTC, DNS-over-HTTPS, speed and a reachability sweep
